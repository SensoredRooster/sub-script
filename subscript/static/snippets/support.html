SubScript keeps rotating diagnostic logs locally while it runs. Create a redacted support bundle when something breaks, then attach it to a tester report.

What gets collected? Runtime heartbeats, request timing, watcher/pipeline events, exceptions, app version, and a redacted configuration snapshot. Form bodies, OAuth payloads, passwords, and access tokens are not intentionally logged.
Before sharing Logs may still contain filenames and local folder paths that help diagnose video-processing problems. Review the ZIP first if those names are sensitive.

Telemetry is local-first. Nothing is uploaded automatically.
