Step 1 of 6 Choose the folder where new videos will appear.

1 / Watch

Where will new clips appear?

Choose the folder your recorder saves clips into. You can also copy or drag finished video files into this folder yourself. When this workflow is active, SubScript watches for new videos automatically.

No extra trigger required OBS, NVIDIA, Medal, another recorder, or a manual file drop can create the file. The new completed video appearing here is what starts the workflow.

Enter a workflow name and an existing folder before continuing.

2 / Clip

What should SubScript use from each new file?

Pick the option that matches what normally lands in this folder.

Use the whole videoBest when your recorder already saves the exact clip you want.
Keep only the last partBest when the recorder saves a longer replay buffer and you only want the final moment.

Choose a valid clip behavior. Replay length must be between 5 and 300 seconds.

3 / Look

How should vertical clips look?

Horizontal footage stays natural. For Shorts, TikTok, and Reels, define how gameplay and a baked-in facecam should be recomposed on a true 9:16 canvas. If you do not need a custom layout, leave Center crop selected.

4 / Review

What should happen after SubScript makes the clip?

Start with review mode until you trust the workflow. You can switch to automatic publishing later.

Review firstSubScript does the work, then waits for you. Nothing posts until you approve it.
AutomaticSubScript processes the new file and continues to the destinations you choose next.

5 / Publish

Where should finished clips go?

Review-first mode does not require a destination. Connect or select destinations now if you want this workflow ready for automatic publishing later.

6 / Activate

Test it once, then turn it on

When active, this workflow will:

Watch {{FOLDER}} for a new completed video, process it with the choices you just made, then send it to review or continue automatically.

Safe test uses the newest video already in the folder as a sample. It always forces review mode and never publishes anything.

Confirm the watched-folder behavior before activating this workflow.
