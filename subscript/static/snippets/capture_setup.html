Set up live clipping — guided setup

Connect your replay recorder, check a sample, then enable your shortcut.

1 / Prepare your recorder

Save a replay first

In OBS, enable Replay Buffer in Settings → Output. In Settings → Hotkeys, assign Save Replay a shortcut. Start Replay Buffer and save a test replay. For another recorder, use its save-clip control.

Use a different shortcut for SubScript. This version processes saved footage; it does not trigger the recorder. Wait for saving to finish before processing.

OBS replay setup guide ↗

2 / Connect SubScript

Where are your replays saved?

Copy the folder from your recorder settings. Use a dedicated replay folder to avoid selecting unrelated recordings.

3 / Verify before you play

Make a test preview

We check the folder, shortcut format, and video processor, then render the latest replay. Tests always stop for review, even in automatic mode. Test previews do not verify in-game shortcut conflicts.

After saving, expand the live replay controls above and select Start watcher. During play: save a replay, wait for saving to finish, then press the SubScript shortcut. If a game blocks the shortcut, test it outside the game.
