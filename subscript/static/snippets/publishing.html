What does “connect an account” mean?

For tonight: TikTok, Instagram, Facebook, X, and Rumble use local upload packs. You can approve a clip, open its platform folder, and upload it yourself. No OAuth setup or account password is needed.

For direct posting later: each network needs its own developer app, client ID/secret, approved posting permissions, a return URL for sign-in, secure token storage and refresh, and a platform-specific upload/status integration. Some platforms also require app review before real accounts can use it.

  • TikTok — developer app + Content Posting API approval + video.upload for drafts or video.publish for direct posts.
  • Instagram/Facebook — Meta developer app, a Professional Instagram account linked to a Facebook Page, the correct Page/Instagram permissions, and Meta app review.
  • X — X developer app, user-context write/media access, and an account/API access plan that permits posting.
  • Rumble — keep using the upload pack until an official supported upload/OAuth path is confirmed.

That is a separate integration project, not something you should have to configure before making clips tonight.

When a clip is ready

Review first is safest: you watch the clip and approve it yourself. Automatic mode skips that check for new clips and should only be used after you are comfortable with the results.

Create titles, descriptions & tags

Supports YouTube, TikTok, Instagram, Facebook, X and Rumble. Turn on destinations below, enter your game and creator name, then generate sample drafts. For an actual clip, use Generate post drafts on its Review card.

Samples use local templates and the information above. They do not save settings, change a clip, render video, or publish anything. Clip drafts also use real captions when available.

Edit each platform draft in Review before approving. Automatic publishing uses the generated drafts immediately. When this is off, YouTube uses its title template and other saved settings.
