# Brand assets

`logo.png` is created automatically on first app launch as a generic **SUB** placeholder.

Replace it anytime in the app **Branding** panel (upload your PNG), or drop your own file here named `logo.png`.

## Music bed (optional)

Drop a short loop / bed as **`music.mp3`** (or set `music.path` in config). When present and `music.enabled` is true, sub-script mixes it under horizontal + vertical at a **low** volume (default `0.10`) so game audio stays clear.

You can also upload MP3 from the app **Captions & music** section. Missing file = skip (fail-soft).
